# Methods reuse audit for Preflight

Methods was inspected through the repository CodeGraph index before code changes. The authoritative source is the Methods C ABI and native tests.

| Need | Existing implementation | Finding / action |
| --- | --- | --- |
| PCA | `cpp/src/core/common/pca_helper.{h,c}` uses the shared SVD in `svd.c`, returns centered training scores, component loadings and `S²/(n−1)` eigenvalues | Internal only. `n4m_preflight_pca_compute` exposes caller-owned outputs through the public C ABI, accepting strided f64 views. No new eigensolver. |
| Full PCA variance moments | PCA helper returns only retained components when truncated | New wrapper computes trace(C) and trace(C²) exactly from the centered data using the smaller of XcXcᵀ and XcᵀXc, without allocating the Gram matrix. It rejects over 250 million products. D_eff must not be computed from the retained eigenvalues alone. |
| Repeatability / ICC | No public pooled per-feature technical-repeat diagnostic or balanced ICC(1,1) | New C ABI takes sample/group IDs and optional per-cell validity mask. It pools within-group SS/df across repeated groups, reports unbalanced ICC as unavailable, and preserves negative balanced ANOVA estimates. |
| Summary / quantiles | Regression metrics include RPIQ-related internal quantile work but no generic finite-value public summary with masks | New summary returns count, min/max, mean, sample SD and type-7 quartiles. |
| Neighbors | Splitters and outlier methods have specific distance use, but no generic public group-excluding nearest-neighbor output | New brute-force Euclidean operation returns sorted indices/distances and unavailable slots, without allocating an n×n distance matrix. |
| HDBSCAN | No clustering, MST or union-find in Methods; reuse assessment in Methods `docs/dev/hdbscan.md` | Generic `n4m_cluster_hdbscan` (ABI 2.19) is a BSD-3 port of scikit-learn 1.9.1 HDBSCAN, with GLOSH and persistence from hdbscan 0.8.44. Equal-weight MST edges are stably sorted. The frozen gate `parity/fixtures/hdbscan_v1.json` checks partitions up to label permutation, membership, GLOSH, persistence and the condensed tree. |
| Adjusted Rand index | None | `n4m_preflight_adjusted_rand_index` matches scikit-learn `adjusted_rand_score`, NaN for identical trivial partitions. |
| Local target contrast | No reusable public metric over a supplied independent-neighbor graph | New C ABI returns continuous `1−roughness/(2s²)` or categorical observed-versus-admissible expected coherence, with equal focal-row weight, coverage and raw same-class fractions. No inference or permutation is done here. |
| SNV view | `n4m_transform_snv_*` (public since ABI 2.0) and the WASM preprocessing registry | Reused unchanged, with mean and population SD (ddof 0) on both hosts. No new symbol. |
| Noise proxy | Savitzky–Golay engine (`savitzky_golay.h`) exists. No public residual-energy reduction with masks, interior-only edges or white-noise normalization exists. | ABI 2.19 `n4m_preflight_noise_proxy_compute` composes the existing SG engine. It derives the residual gain from the filter's own impulse response and returns per-band and pooled RMS residuals with per-band counts. |
| Pairs within tolerance | k-NN caps the neighbor count, so it cannot give exact counts of every pair within a radius | ABI 2.19 `n4m_preflight_pairs_within_tolerance` covers both the within-matrix and query × reference cases. It applies group exclusion, returns exact totals and candidate counts, per-row flags and a bounded ordered list, and treats overflowing differences as distant. |
| PLS / PCR for the validation probe | `models.pls.pls_regression` and `models.pls.pcr` role estimators | Reused unchanged through DAG-ML controllers: `MethodsEstimatorController` on CPU, `N4mWasmRegressionController` (`RolePipeline`) in the browser. Preflight calls no PLS symbol directly. Known limit: absolute `DBL_EPSILON` thresholds in NIPALS refuse strongly scaled data with `NumericalFailure`. No Methods classifier is qualified on every host, so the classification probe stays unavailable. |
| Repeat aggregation and probe scores | None generic with a declared domain | ABI 2.20 adds `n4m_stats_group_means` (double-double per-group means) and `n4m_stats_regression_scores` (RMSE/MAE/R² from explicit residuals and deviations around a double-double mean). Both accept finite values with nonzero \|x\| in [2^-256, 2^256]. Regression scores also require a spread ≤ 2^32 (rule 15). Both refuse outside with `N4M_ERR_UNSUPPORTED`, and errors are of order n·ε. JS: `statsGroupMeans` and `statsRegressionScores`. |
| Metadata–Y association | No public factor association statistic, permutation test or multiplicity adjustment; PCG64 existed with NumPy-parity streams but its interval sampler was private to one augmenter | ABI 2.19 adds `n4m_preflight_factor_association` (eta², ANOVA F, Cramér V, Pearson χ², distinct-outcome bound, Monte Carlo p-value over one exchangeable block) and `n4m_preflight_holm_adjust`. A shared engine helper reproduces NumPy `random_interval` and `Generator.permutation`, so `default_rng(seed).permutation(n)` regenerates every draw. |
| Correlation of continuous metadata with Y | No bivariate correlation test or rank transform in the public ABI (the correlation filter is a fitted feature selector; ranks were private to AUC) | Generic ABI 2.20 `n4m_stats_correlation_test` (Pearson, or Spearman on average ranks) reuses the PCG64 NumPy-parity permutation of the factor kernel; two-sided Monte Carlo p-value on \|r\|. |
| Exact permutation resolution | Only a combinatorial log10 bound on distinct arrangements | Generic ABI 2.20 `n4m_stats_factor_association_exact` and `n4m_stats_correlation_exact` enumerate the distinct arrangements of the smaller side and return N, the exact p-value and the minimal attainable exact p-value. |
| Benjamini–Hochberg | Only Holm | Generic ABI 2.20 `n4m_stats_bh_adjust` (R `p.adjust("BH")`), used only for an exploratory secondary view. |
| Confounding (PERMANOVA, PERMDISP) | No multivariate ANOVA, design-rank or dispersion test; the PCG64 permutation helper of the association kernel existed | ABI 2.20 adds generic `n4m_stats_permanova` (one categorical term on Euclidean distances, optionally given strata: total, strata, term and residual SS of the additive model, R², partial R², pseudo-F, identifiable df from the connected components of the level-stratum graph, within-strata Monte Carlo test) `n4m_stats_permanova_freedman_lane` (partial test given additive condition main effects, Freedman–Lane permutation of reduced-model residuals; vegan implements neither its `by = "margin"` raw-response scheme nor its partial-`permutest` scheme as Freedman–Lane, so an independent lstsq refit oracle is the reference and the vegan schemes are recorded for information) and `n4m_stats_permdisp` (vegan `betadisper(type = "centroid")` + `permutest`). All reuse the PCG64 permutation helper, count permuted `F >= F_obs − sqrt(eps)` as vegan, and rescale sums of squares with `scalbn` after exact power-of-two scaling and per-column centring. Written from the closed forms (Anderson 2001, 2006); scikit-bio (BSD-3) and NumPy/SciPy are test-only references, nothing is vendored or ported. |

The public functions are in `cpp/include/n4m/metrics.h`. The PCA, repeatability, summary, neighbor and local-contrast diagnostics are ABI 2.18.0 (Methods 1.3.5); HDBSCAN, ARI, the noise proxy, tolerance pairs, factor association and Holm adjustment are ABI 2.19.0 (Methods 1.3.6); the correlation test, exact enumerations and Benjamini–Hochberg adjustment, PERMANOVA and PERMDISP are ABI 2.20.0 (unreleased Methods branch), which Preflight now requires. Thin npm wrappers in `bindings/js/src/preflightDiagnostics.ts` call the same Emscripten exports, and the WASM bridge reuses the registry SNV operator (`ppCreate("StandardNormalVariate")`). Every output array belongs to the caller. Native Methods validates shapes, types, positive strides, offset overflow and finite unmasked values; the caller must still guarantee that pointers refer to sufficiently large live allocations. Missing numeric outputs use NaN at this ABI level and must be converted to null by JSON-producing layers. There is no implicit imputation, automatic mask construction, or alternative scientific implementation in a language binding.

The hand-computed native test covers rank-one PCA and exact moments, column-major input/strided outputs, balanced and negative ICC, masked unbalanced repeats, quartiles, group-excluding neighbors, and continuous/categorical local contrast. Extreme finite values check representable summary SD and neighbor distances, while unrepresentable outputs return a numerical error. The Emscripten export list is generated from the ABI symbol snapshot, so the five functions enter the WASM module after snapshot regeneration.

The ABI 2.19 tests also check against independent values. Noise proxy: the five-point quadratic SG weights `(−3,12,17,12,−3)/35` with gain² = 18/35, impulse residuals, masked windows, untouched edges, column-major storage and a white-noise statistical reference. Pairs: RMS distances, group exclusion, truncated listing with exact totals, the two-matrix mode and overflow. Association: hand-computed eta²/F/χ²/Cramér V and Holm values, plus permutation counts from NumPy 2.2.6 `default_rng(seed).permutation(n)` with SciPy 1.15.3, recorded as test-only constants; ties count `>= observed − sqrt(DBL_EPSILON)` on the eta² or V² scale. HDBSCAN: the frozen `hdbscan_v1` fixture from scikit-learn 1.9.1 and hdbscan 0.8.44 on eight cases, partitions identical up to label permutation and continuous outputs within 1e-12, in native and WASM.

The ABI 2.20 tests pin SciPy 1.15.3 `pearsonr`/`spearmanr` coefficients, NumPy 2.2.6 permutation counts, statsmodels 0.15.0 `multipletests(method="fdr_bh")` and SciPy `false_discovery_control` values, and brute-force enumerations of all n! permutations for the exact kernels (for example the perfect 2×2 table: 70 arrangements, minimal exact p = 1/35). The same release fixes the centering of `n4m_preflight_factor_association`: a naive mean after division by max|y| leaked a large common offset into the between-group sum (two identical groups at 1e16 gave eta² = 0.27). Both association kernels now center after an exact power-of-two scaling, a shift to the first value and a residual-mean correction, with translation-invariance tests.

The ABI 2.20 gate `parity/fixtures/permanova_v1.json` (generator `parity/generators/permanova_v1.py`, test `n4m_permanova_tests`, also run by the JS/WASM tests) compares PERMANOVA sums of squares, R², pseudo-F and df with NumPy 2.2.6 `lstsq` on full one-hot designs (a different algorithm from the native reduced normal equations), free pseudo-F with scikit-bio 0.7.4 `permanova`, PERMDISP F with SciPy 1.15.3 `f_oneway` and scikit-bio `permdisp(test="centroid")`, and every Monte Carlo count with a NumPy `default_rng` reproduction of the draw convention. Cases: free one-factor, two crossed factors given strata, the same data free, partial aliasing (df 2 of 3), full aliasing (df 0, no test), singleton and constant strata, dispersion without location effect, and a PERMDISP boundary case where comparing on F (vegan) gives b = 0 while the former comparison on B/(B+W) gave 22. The PERMDISP counting oracle transcribes vegan `permutest.betadisper` (residuals permuted and refitted by least squares, F compared). Scale cases (six values ±1e-162 give the smallest subnormal SS; 1e155 + 1e140·k gives finite SS near 2.3e282) run natively and in WASM. Hand-derived closed forms cover the one-way case (b = 93, equal to the association golden), a balanced 2×2 (F = 20), aliasing, constant data and a PERMDISP F of 15/16. R with vegan was not installed, so vegan itself was not run.
