# Methods reuse audit for Preflight

Methods was inspected through the repository CodeGraph index before code changes. The authoritative source is the Methods C ABI and native tests.

| Need | Existing implementation | Finding / action |
| --- | --- | --- |
| PCA | `cpp/src/core/common/pca_helper.{h,c}` uses the shared SVD in `svd.c`, returns centered training scores, component loadings and `S²/(n−1)` eigenvalues | Internal only. `n4m_preflight_pca_compute` exposes caller-owned outputs through the public C ABI, accepting strided f64 views. No new eigensolver. |
| Full PCA variance moments | PCA helper returns only retained components when truncated | New wrapper computes trace(C) and trace(C²) exactly from the centered data using the smaller of XcXcᵀ and XcᵀXc, without allocating the Gram matrix. It rejects over 250 million products. D_eff must not be computed from the retained eigenvalues alone. |
| Repeatability / ICC | No public pooled per-feature technical-repeat diagnostic or balanced ICC(1,1) | New C ABI takes sample/group IDs and optional per-cell validity mask. It pools within-group SS/df across repeated groups, reports unbalanced ICC as unavailable, and preserves negative balanced ANOVA estimates. |
| Summary / quantiles | Regression metrics include RPIQ-related internal quantile work but no generic finite-value public summary with masks | New summary returns count, min/max, mean, sample SD and type-7 quartiles. |
| Neighbors | Splitters and outlier methods have specific distance use, but no generic public group-excluding nearest-neighbor output | New brute-force Euclidean operation returns sorted indices/distances and unavailable slots, without allocating an n×n distance matrix. |
| HDBSCAN | No clustering, MST or union-find in Methods; reuse assessment in Methods `docs/dev/hdbscan.md` | Generic `n4m_cluster_hdbscan` (ABI 2.19) is a BSD-3 port of scikit-learn 1.9.1 HDBSCAN, with GLOSH and persistence from hdbscan 0.8.44. Equal-weight MST edges are stably sorted. The frozen gate `parity/fixtures/hdbscan_v1.json` checks partitions up to label permutation, membership, GLOSH, persistence and the condensed tree. |
| Adjusted Rand index | None | `n4m_preflight_adjusted_rand_index` matches scikit-learn `adjusted_rand_score`, NaN for identical trivial partitions. |
| Local target contrast | No reusable public metric over a supplied independent-neighbor graph | New C ABI returns continuous `1−roughness/(2s²)` or categorical observed-versus-admissible expected coherence, with equal focal-row weight, coverage and raw same-class fractions. No inference or permutation is done here. |
| SNV view | `n4m_transform_snv_*` (public since ABI 2.0) and the WASM preprocessing registry | Reused, with mean and population SD (ddof 0) on both hosts. No new symbol. Since ABI 2.20, the SNV engine handles a constant finite row as exact zeros. It rescales each finite row by a power of two and uses compensated sums with a refined mean, so `[1e200, 0, −1e200]` and `[2⁻¹⁰⁷⁴, 0, −2⁻¹⁰⁷⁴]` both give `[√1.5, 0, −√1.5]`. A non-finite result is a numerical failure. The mean is a compensated double-double, so offsets near 1e16 or 1e300 do not leak into the deviations. The new `n4m_preflight_snv_compute` (JS `preflightSnv`) also aggregates repeats by group with compensated means. It returns the per-row or per-group rounding bound that the SNV rank criterion uses. |
| Noise proxy | Savitzky–Golay engine (`savitzky_golay.h`) exists. No public residual-energy reduction with masks, interior-only edges or white-noise normalization exists. | ABI 2.19 `n4m_preflight_noise_proxy_compute` composes the existing SG engine. It derives the residual gain from the filter's own impulse response and returns per-band and pooled RMS residuals with per-band counts. Since Methods 1.3.7, it accepts only the verified domain (odd window 3..1001, polyorder ≤ min(10, window − 2)), and it checks the polynomial reproduction moments of the weights within 1e-9. Since ABI 2.20, each row is centred on a valid value and rescaled by a power of two before smoothing, and residuals are accumulated in scaled sums of squares. The proxy is therefore translation invariant and power-of-two equivariant over the whole finite range, and overflow is `N4M_ERR_NUMERICAL_FAILURE`. |
| Pairs within tolerance | k-NN caps the neighbor count, so it cannot give exact counts of every pair within a radius | ABI 2.19 `n4m_preflight_pairs_within_tolerance` covers both the within-matrix and query × reference cases. It applies group exclusion, returns exact totals and candidate counts, per-row flags and a bounded ordered list, and treats overflowing differences as distant. Reference contradictions between the returned pairs are comparisons of declared values in Preflight Rust; no new symbol. Since ABI 2.20, the differences are rescaled by an exact power of two (exact halves when q − r overflows) and summed with compensation. The RMS is then compared with the tolerance in that scaled space, before the published distance is rounded, so `[2⁻¹⁰⁷³,0]` against `[0,0]` at tolerance 2⁻¹⁰⁷⁴ is far. A positive distance below 2⁻¹⁰⁷⁴ is published as 2⁻¹⁰⁷⁴. `[1e308,0]` against `[-1e308,0]` at tolerance 1.5e308 is a pair. The listed distance does not depend on the tolerance: `[1e-170,0]` against `[0,0]` gives 7.07e-171 at every tolerance. |
| Metadata–Y association | No public factor association statistic, permutation test or multiplicity adjustment; PCG64 existed with NumPy-parity streams but its interval sampler was private to one augmenter | ABI 2.19 adds `n4m_preflight_factor_association` (eta², ANOVA F, Cramér V, Pearson χ², distinct-outcome bound, Monte Carlo p-value over one exchangeable block) and `n4m_preflight_holm_adjust`. A shared engine helper reproduces NumPy `random_interval` and `Generator.permutation`, so `default_rng(seed).permutation(n)` regenerates every draw. |

The public functions are in `cpp/include/n4m/metrics.h`. The PCA, repeatability, summary, neighbor and local-contrast diagnostics are ABI 2.18.0 (Methods 1.3.5); HDBSCAN, ARI, the noise proxy, tolerance pairs, factor association and Holm adjustment are ABI 2.19.0 (Methods 1.3.6). The bounded SNV `n4m_preflight_snv_compute` is ABI 2.20.0, which Preflight now requires. Thin npm wrappers in `bindings/js/src/preflightDiagnostics.ts` call the same Emscripten exports, and both hosts call `n4m_preflight_snv_compute` for SNV. Every output array belongs to the caller. Native Methods validates shapes, types, positive strides, offset overflow and finite unmasked values; the caller must still guarantee that pointers refer to sufficiently large live allocations. Missing numeric outputs use NaN at this ABI level and must be converted to null by JSON-producing layers. There is no implicit imputation, automatic mask construction, or alternative scientific implementation in a language binding.

The hand-computed native test covers rank-one PCA and exact moments, column-major input/strided outputs, balanced and negative ICC, masked unbalanced repeats, quartiles, group-excluding neighbors, and continuous/categorical local contrast. Extreme finite values check representable summary SD and neighbor distances, while unrepresentable outputs return a numerical error. The Emscripten export list is generated from the ABI symbol snapshot, so the five functions enter the WASM module after snapshot regeneration.

Magnitude-sweep property tests (`cpp/tests/test_preflight_robustness.cpp` and the JS suite) cover SNV, the noise proxy and tolerance pairs at scales 2⁻¹⁰⁷⁴..2¹⁰⁰⁰, with exact offsets and huge constant columns. The ABI 2.19 tests also check against independent values. Noise proxy: the five-point quadratic SG weights `(−3,12,17,12,−3)/35` with gain² = 18/35, impulse residuals, masked windows, untouched edges, column-major storage and a white-noise statistical reference. Pairs: RMS distances, group exclusion, truncated listing with exact totals, the two-matrix mode and overflow. Association: hand-computed eta²/F/χ²/Cramér V and Holm values, plus permutation counts from NumPy 2.2.6 `default_rng(seed).permutation(n)` with SciPy 1.15.3, recorded as test-only constants; ties count `>= observed − sqrt(DBL_EPSILON)` on the eta² or V² scale. HDBSCAN: the frozen `hdbscan_v1` fixture from scikit-learn 1.9.1 and hdbscan 0.8.44 on eight cases, partitions identical up to label permutation and continuous outputs within 1e-12, in native and WASM.
