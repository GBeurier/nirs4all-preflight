# Methods reuse audit for Preflight

Methods was inspected through the repository CodeGraph index before code changes. The authoritative source is the Methods C ABI and native tests.

| Need | Existing implementation | Finding / action |
| --- | --- | --- |
| PCA | `cpp/src/core/common/pca_helper.{h,c}` uses the shared SVD in `svd.c`, returns centered training scores, component loadings and `S²/(n−1)` eigenvalues | Internal only. `n4m_preflight_pca_compute` exposes caller-owned outputs through the public C ABI, accepting strided f64 views. No new eigensolver. ABI 2.20 `n4m_preflight_pca_compute_resolved`, which Preflight uses, adds the absolute accuracy threshold `16 * max(n,p) * eps * lambda_max` and per-component unresolved flags (variance and scores 0, never counted as rank). The supported domain is nonzero \|x\| in [2^-128, 2^128] with max/min nonzero \|x\| <= 2^32; outside it the call is refused. |
| Full PCA variance moments | PCA helper returns only retained components when truncated | New wrapper computes trace(C) and trace(C²) exactly from the centered data using the smaller of XcXcᵀ and XcᵀXc, without allocating the Gram matrix. It rejects over 250 million products. D_eff must not be computed from the retained eigenvalues alone. |
| Repeatability / ICC | No public pooled per-feature technical-repeat diagnostic or balanced ICC(1,1) | New C ABI takes sample/group IDs and optional per-cell validity mask. It pools within-group SS/df across repeated groups, reports unbalanced ICC as unavailable, and preserves negative balanced ANOVA estimates. |
| Summary / quantiles | Regression metrics include RPIQ-related internal quantile work but no generic finite-value public summary with masks | New summary returns count, min/max, mean, sample SD and type-7 quartiles. |
| Neighbors | Splitters and outlier methods have specific distance use, but no generic public group-excluding nearest-neighbor output | New brute-force Euclidean operation returns sorted indices/distances and unavailable slots, without allocating an n×n distance matrix. |
| HDBSCAN | No clustering, MST or union-find in Methods; reuse assessment in Methods `docs/dev/hdbscan.md` | Generic `n4m_cluster_hdbscan` (ABI 2.19) is a BSD-3 port of scikit-learn 1.9.1 HDBSCAN, with GLOSH and persistence from hdbscan 0.8.44. Equal-weight MST edges are stably sorted. ABI 2.20 fixes out-of-bounds writes found by review and adopts the rules 13/15 numerical domain (finite, nonzero |x| in [2^-256, 2^256], max/min nonzero |x| <= 2^32, Methods macros `N4M_DOMAIN_MAX_MAGNITUDE_LOG2` and `N4M_DOMAIN_MAX_SPREAD_LOG2`): outside it HDBSCAN, assignment and Gaussian draws refuse with `N4M_ERR_UNSUPPORTED` before computing; inside it HDBSCAN keeps the reference operation order, the assignment is an exact optimum (192-bit fixed-point duals, no centring) and the draws scale exactly. Every call checks a 256 MiB working-memory budget before allocating; ARI uses exact integer products. |
| Adjusted Rand index | None | `n4m_preflight_adjusted_rand_index` matches scikit-learn `adjusted_rand_score`, NaN for identical trivial partitions. |
| Cluster matching | No assignment solver or cluster-overlap table | ABI 2.20 `n4m_cluster_jaccard_matrix` (new, about 30 lines, checked against scikit-learn `contingency_matrix`) and `n4m_linear_sum_assignment`, a BSD-3 port of SciPy 1.18.1 `rectangular_lsap` (Crouse's shortest augmenting path) kept with its tie order in `cpp/src/core/optimization/_vendored`. LAPJV (`gatagat/lap`, BSD-2) has another tie order; dlib's solver is integer-only; Rust crates cannot be linked. |
| Subsampling plans and Gaussian null draws | PCG64 with NumPy `permutation` and Ziggurat `standard_normal` parity existed internally | ABI 2.20 `n4m_random_permutations` (successive `default_rng(seed).permutation(n)`) and `n4m_random_multivariate_normal` (`multivariate_normal(..., method="cholesky")`) expose them. No new sampler; a small lower Cholesky lives with the kernel, and its storage, cost and draw limits are checked before any allocation, also for zero draws. Reference gate: Methods `parity/fixtures/cluster_matching_null_v1.json` (NumPy 2.4.6, SciPy 1.18.1, scikit-learn 1.9.1, including HDBSCAN on simulated Gaussian data). |
| Local target contrast | No reusable public metric over a supplied independent-neighbor graph | New C ABI returns continuous `1−roughness/(2s²)` or categorical observed-versus-admissible expected coherence, with equal focal-row weight, coverage and raw same-class fractions. No inference or permutation is done here. |
| SNV view | `n4m_transform_snv_*` (public since ABI 2.0) and the WASM preprocessing registry | Both hosts call ABI 2.20 `n4m_preflight_snv_compute` (JS `preflightSnv`), which composes the SNV engine (mean and population SD, ddof 0). Since Methods 1.3.7, the SNV engine handles a constant finite row as exact zeros. It rescales each finite row by a power of two and uses compensated sums with a refined mean, so `[1e200, 0, −1e200]` and `[2⁻¹⁰⁷⁴, 0, −2⁻¹⁰⁷⁴]` both give `[√1.5, 0, −√1.5]`. A non-finite result is a numerical failure. The mean is a compensated double-double, so offsets near 1e16 or 1e300 do not leak into the deviations. `n4m_preflight_snv_compute` also aggregates repeats by group with compensated means. It returns the per-row or per-group rounding bound that the SNV rank criterion uses. |
| Noise proxy | Savitzky–Golay engine (`savitzky_golay.h`) exists. No public residual-energy reduction with masks, interior-only edges or white-noise normalization exists. | ABI 2.19 `n4m_preflight_noise_proxy_compute` composes the existing SG engine. It derives the residual gain from the filter's own impulse response and returns per-band and pooled RMS residuals with per-band counts. Since Methods 1.3.7, it accepts only the verified domain (odd window 3..1001, polyorder ≤ min(10, window − 2)), and it checks the polynomial reproduction moments of the weights within 1e-9. Since ABI 2.20, each window's residual is computed from the window alone. Its second differences are kept exactly until a double-double weighted sum, with double-double Gram-polynomial weights cross-checked against the SG engine. As a result:
- a value outside every evaluable window never changes the results;
- the proxy is translation invariant for exact offsets and power-of-two equivariant;
- `[-2^60, 2^60, 1, 0, 0]` gives its analytic `sqrt(4/5)`. |
| Pairs within tolerance | k-NN caps the neighbor count, so it cannot give exact counts of every pair within a radius | ABI 2.19 `n4m_preflight_pairs_within_tolerance` covers both the within-matrix and query × reference cases. It applies group exclusion, returns exact totals and candidate counts, per-row flags and a bounded ordered list, and treats overflowing differences as distant. Reference contradictions between the returned pairs are comparisons of declared values in Preflight Rust; no new symbol. Since ABI 2.20, decisions are exact. A fast estimate on power-of-two rescaled differences settles pairs farther than 2⁻⁴⁵ (relative) from the tolerance. The other pairs compare `Σ(q − r)²` with `cols·tol²` exactly, in a fixed-point accumulator of exact products. An accepted pair lists min(RMS, tolerance), at least 2⁻¹⁰⁷⁴. `[1e308,0]` against `[-1e308,0]` at tolerance 1.5e308 is a pair. The listed distance does not depend on the tolerance: `[1e-170,0]` against `[0,0]` gives 7.07e-171 at every tolerance. |
| Unbalanced ICC, REML and repeatability intervals | `n4m_preflight_repeatability_compute` covered pooled SD and balanced ANOVA ICC only. Methods had no mixed-model or variance-component solver. Its only F quantile was a private, low-precision Numerical Recipes routine inside Hotelling T². lme4 (GPL-2-or-later, R/C++) is not callable without R, and its general sparse PLS machinery is far larger than the one-way model needs. | ABI 2.20 adds the generic `n4m_stats_variance_components_reml` and `n4m_stats_variance_components_intervals`, written from the published REML equations (Patterson & Thompson 1971; Harville 1977); no code was ported. s2_within is profiled out, the profiled criterion and its derivative are gridded on gamma, every local maximum is bisected and the largest restricted likelihood is kept (review b9: unbalanced designs can be multimodal); each band is rescaled by exact powers of two from its centred variation and values outside the rule-13 domain are refused. The functions return boundary and convergence status per feature, exact chi-square and Searle F intervals, and NumPy-parity PCG64 cluster-bootstrap percentiles. Chi-square/F quantiles (`core/common/distributions.cpp`) use the incomplete gamma and beta functions (DLMF 8.7, 8.9, 8.17) with bisection. |
| PLS / PCR for the validation probe | `models.pls.pls_regression` and `models.pls.pcr` role estimators | Reused unchanged through DAG-ML controllers: `MethodsEstimatorController` on CPU, `N4mWasmRegressionController` (`RolePipeline`) in the browser. Preflight calls no PLS symbol directly. Methods 1.3.7 makes PLS regression (every solver) and PCR without autoscaling scale-equivariant, which removes the former absolute-`DBL_EPSILON` refusals of strongly scaled data. No Methods classifier is qualified on every host, so the classification probe stays unavailable. |
| Repeat aggregation and probe scores | None generic with a declared domain | ABI 2.20 adds `n4m_stats_group_means` (double-double per-group means) and `n4m_stats_regression_scores` (RMSE/MAE/R² from explicit residuals and deviations around a double-double mean). Both accept finite values with nonzero \|x\| in [2^-256, 2^256]. Regression scores also require a spread ≤ 2^32 (rule 15). Both refuse outside with `N4M_ERR_UNSUPPORTED`, and errors are of order n·ε. JS: `statsGroupMeans` and `statsRegressionScores`. |
| Metadata–Y association | No public factor association statistic, permutation test or multiplicity adjustment; PCG64 existed with NumPy-parity streams but its interval sampler was private to one augmenter | ABI 2.19 adds `n4m_preflight_factor_association` (eta², ANOVA F, Cramér V, Pearson χ², distinct-outcome bound, Monte Carlo p-value over one exchangeable block) and `n4m_preflight_holm_adjust`. A shared engine helper reproduces NumPy `random_interval` and `Generator.permutation`, so `default_rng(seed).permutation(n)` regenerates every draw. |
| Correlation of continuous metadata with Y | No bivariate correlation test or rank transform in the public ABI (the correlation filter is a fitted feature selector; ranks were private to AUC) | Generic ABI 2.20 `n4m_stats_correlation_test` (Pearson, or Spearman on average ranks) reuses the PCG64 NumPy-parity permutation of the factor kernel; two-sided Monte Carlo p-value on \|r\|. |
| Exact permutation resolution | Only a combinatorial log10 bound on distinct arrangements | Generic ABI 2.20 `n4m_stats_factor_association_exact` and `n4m_stats_correlation_exact` enumerate the distinct arrangements of the smaller side and return N, the exact p-value and the minimal attainable exact p-value. |
| Benjamini–Hochberg | Only Holm | Generic ABI 2.20 `n4m_stats_bh_adjust` (R `p.adjust("BH")`), used only for an exploratory secondary view. |
| Confounding (PERMANOVA, PERMDISP) | No multivariate ANOVA, design-rank or dispersion test; the PCG64 permutation helper of the association kernel existed | ABI 2.20 adds generic `n4m_stats_permanova` (one categorical term on Euclidean distances, optionally given strata: total, strata, term and residual SS of the additive model, R², partial R², pseudo-F, identifiable df from the connected components of the level-stratum graph, within-strata Monte Carlo test) `n4m_stats_permanova_freedman_lane` (partial test given additive condition main effects, Freedman–Lane permutation of reduced-model residuals; vegan implements neither its `by = "margin"` raw-response scheme nor its partial-`permutest` scheme as Freedman–Lane, so an independent lstsq refit oracle is the reference and the vegan schemes are recorded for information) and `n4m_stats_permdisp` (vegan `betadisper(type = "centroid")` + `permutest`). All reuse the PCG64 permutation helper, count permuted `F >= F_obs − sqrt(eps)` as vegan, and rescale sums of squares with `scalbn` after exact power-of-two scaling and per-column centring. Written from the closed forms (Anderson 2001, 2006); scikit-bio (BSD-3) and NumPy/SciPy are test-only references, nothing is vendored or ported. |
| Domain shift | `n4m_outlier_detection_hotelling_t2` / `_q_residuals` evaluate the fitted rows only, need n ≥ p and use Gaussian limits; PLS monitoring needs a PLS model; no energy distance or two-sample test | ABI 2.20 adds the generic `n4m_stats_energy_distance` (energy distances with conservative rounding estimates, K-sample statistic, PCG64 permutation test under the declared relative tie rule with undecidable draws counted apart) and `n4m_stats_pca_monitor` (reference PCA through the shared PCA helper with components above the eigenvalue resolution, T²/Q of new rows, out-of-fold empirical limits, counts beyond the limits by more than a conservative tolerance and counts within it). Both refuse inputs outside the supported domain (nonzero \|x\| in [2^-256, 2^256], spread ≤ 2^32). |

The public functions are in `cpp/include/n4m/metrics.h`. The variance components are ABI 2.20.0. Their native and JS tests compare with independent references recorded as test-only constants and regenerated by `parity/generators/variance_components_v1.py`. These are dense-matrix REML solved on the Harville score equations (NumPy 2.5.4, SciPy 1.18.1), statsmodels 0.15.0 MixedLM REML (within its 1e-6 optimizer tolerance), balanced closed forms (REML equals ANOVA when MSB > MSW, and s2_between = 0 with the sample variance otherwise), SciPy chi2/F quantiles up to 150,000 df, and a NumPy-redrawn cluster bootstrap refitted with the dense REML. The PCA, repeatability, summary, neighbor and local-contrast diagnostics are ABI 2.18.0 (Methods 1.3.5); HDBSCAN, ARI, the noise proxy, tolerance pairs, factor association and Holm adjustment are ABI 2.19.0 (Methods 1.3.6); ABI 2.20.0 (Methods 1.3.7), which Preflight requires, adds the correlation test, exact enumerations, Benjamini–Hochberg, PERMANOVA, PERMDISP, Freedman–Lane, energy distance, PCA monitoring, one-way variance components, group means, regression scores, the bounded SNV, the resolved PCA, cluster Jaccard, linear sum assignment, random permutations and multivariate normal draws. Thin npm wrappers in `bindings/js/src/preflightDiagnostics.ts` call the same Emscripten exports, and both hosts call `n4m_preflight_snv_compute` for SNV. Every output array belongs to the caller. Native Methods validates shapes, types, positive strides, offset overflow and finite unmasked values; the caller must still guarantee that pointers refer to sufficiently large live allocations. Missing numeric outputs use NaN at this ABI level and must be converted to null by JSON-producing layers. There is no implicit imputation, automatic mask construction, or alternative scientific implementation in a language binding.

The hand-computed native test covers rank-one PCA and exact moments, column-major input/strided outputs, balanced and negative ICC, masked unbalanced repeats, quartiles, group-excluding neighbors, and continuous/categorical local contrast. Extreme finite values check representable summary SD and neighbor distances, while unrepresentable outputs return a numerical error. The Emscripten export list is generated from the ABI symbol snapshot, so the five functions enter the WASM module after snapshot regeneration.

The ABI 2.19 tests also check against independent values. Noise proxy: the five-point quadratic SG weights `(−3,12,17,12,−3)/35` with gain² = 18/35, impulse residuals, masked windows, untouched edges, column-major storage and a white-noise statistical reference. Pairs: RMS distances, group exclusion, truncated listing with exact totals, the two-matrix mode and overflow. Association: hand-computed eta²/F/χ²/Cramér V and Holm values, plus permutation counts from NumPy 2.2.6 `default_rng(seed).permutation(n)` with SciPy 1.15.3, recorded as test-only constants; ties count `>= observed − sqrt(DBL_EPSILON)` on the eta² or V² scale. HDBSCAN: the frozen `hdbscan_v1` fixture from scikit-learn 1.9.1 and hdbscan 0.8.44 on eight cases, partitions identical up to label permutation and continuous outputs within 1e-12, in native and WASM.

The ABI 2.20 tests pin SciPy 1.15.3 `pearsonr`/`spearmanr` coefficients, NumPy 2.2.6 permutation counts, statsmodels 0.15.0 `multipletests(method="fdr_bh")` and SciPy `false_discovery_control` values, and brute-force enumerations of all n! permutations for the exact kernels (for example the perfect 2×2 table: 70 arrangements, minimal exact p = 1/35). The same release fixes the centering of `n4m_preflight_factor_association`: a naive mean after division by max|y| leaked a large common offset into the between-group sum (two identical groups at 1e16 gave eta² = 0.27). Both association kernels now center after an exact power-of-two scaling, a shift to the first value and a residual-mean correction, with translation-invariance tests.

The ABI 2.20 gate `parity/fixtures/permanova_v1.json` (generator `parity/generators/permanova_v1.py`, test `n4m_permanova_tests`, also run by the JS/WASM tests) compares PERMANOVA sums of squares, R², pseudo-F and df with NumPy 2.2.6 `lstsq` on full one-hot designs (a different algorithm from the native reduced normal equations), free pseudo-F with scikit-bio 0.7.4 `permanova`, PERMDISP F with SciPy 1.15.3 `f_oneway` and scikit-bio `permdisp(test="centroid")`, and every Monte Carlo count with a NumPy `default_rng` reproduction of the draw convention. Cases: free one-factor, two crossed factors given strata, the same data free, partial aliasing (df 2 of 3), full aliasing (df 0, no test), singleton and constant strata, dispersion without location effect, and a PERMDISP boundary case where comparing on F (vegan) gives b = 0 while the former comparison on B/(B+W) gave 22. The PERMDISP counting oracle transcribes vegan `permutest.betadisper` (residuals permuted and refitted by least squares, F compared). Scale cases (six values ±1e-162 give the smallest subnormal SS; 1e155 + 1e140·k gives finite SS near 2.3e282) run natively and in WASM. Hand-derived closed forms cover the one-way case (b = 93, equal to the association golden), a balanced 2×2 (F = 20), aliasing, constant data and a PERMDISP F of 15/16. R with vegan was not installed, so vegan itself was not run.

The domain-shift kernels are gated by `parity/fixtures/domain_shift_v1.json` (generator `parity/generators/domain_shift_v1.py`, NumPy 2.2.6 and SciPy 1.15.3). Its oracles never reuse the kernels' rounding formulas: exact rational energies and exact rational permutation statistics under the declared tie rule, rational inverse covariance (k = p) or axis-aligned exact T² and Q with rational type-7 limits and exact decisions, and NumPy SVD only for generic cases. Native and WASM tests check the inclusion of the rational energies in the published estimates without slack, the declared-rule p-value (476/999 on the Astra tie case), the ill-conditioned Astra T² target reported near the limit, domain boundaries at the 2^32 spread and power-of-two sweeps. Preflight's end-to-end tests recompute comparisons, seeds (protocol `domain_shift.v2`), permutation counts and the Holm adjustment independently in NumPy.

The SNV, noise-proxy, tolerance-pair, nearest-neighbour and local-contrast (continuous targets) kernels share one supported numerical domain: every nonzero |x| in [2⁻²⁵⁶, 2²⁵⁶] and, per row, max/min nonzero |x| ≤ 2³² (lead rules 13 and 15). The summary and nearest-neighbour kernels keep only the magnitude bound. Inputs outside it are refused before computing with `N4M_ERR_UNSUPPORTED` and the message "input outside the supported numerical domain". Both providers map that refusal to the reason `NUMERICAL_DOMAIN_EXCEEDED`, and the metric publishes the domain in `numerical_domain`.


Magnitude-sweep property tests (`cpp/tests/test_preflight_robustness.cpp` and the JS suite) cover SNV, the noise proxy and tolerance pairs at scales 2⁻¹⁰⁷⁴..2¹⁰⁰⁰, with exact offsets, huge constant columns and mixed exponents within a row. They use independent oracles: exact rational pair decisions and 400-digit SNV references. The ABI 2.19 tests also check against independent values.
