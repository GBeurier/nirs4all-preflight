| Between-sample SD per band. Balanced ICC(1,1): σb = σw·√(ICC/(1−ICC)) = √((MSB−MSW)/r), exact algebra in TS. Unbalanced (REML ICC(1)), wave 3: σb = √σb² read from the engine's own REML components (`sigma2_between` / `sigma2_within` parameters of `measurement.icc_1_reml`, Methods `stats_variance_components_reml`), R = √(σb²/σw²); exact, no longer labelled "approximate". The approximation remains only as a fallback when a report lacks the components (`betweenKind: "approximate"`). Validated on the real engine with an unbalanced pitfalls set (`reml.engine.test.ts`): σb²/(σb²+σw²) equals the engine REML ICC per band (1e-10), and the Methods REML kernel run locally on `contextGroups` reproduces the engine components (relative 1e-9), which also validates the demo's mirror of `analyze_repeats` grouping | `profiles.ts:betweenSampleSd`, `remlComponents`, `repeatProfiles` | Preflight engine (`measurement.between_sample_sd`) + nirs4all-ui (`extractRepeatability` exposing the REML components) | The components are only in metric parameters; the nirs4all-ui extractor does not expose them, so the demo reads the raw parameters | Engine emits σb (ANOVA and REML) per band as a metric, nirs4all-ui extracts it; drop `betweenSampleSd` and `remlComponents` |
