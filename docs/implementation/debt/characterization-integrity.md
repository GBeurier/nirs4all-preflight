# Characterization debt — integrity, SNR and diversity panels (demo)

Scope: `demo/src/characterization/integrity/` (request sections 3–5 and their section 10 comments).
Every entry below is interim in the demo and has a target owner.

| What | Where | Target owner | Why interim | Migration |
| --- | --- | --- | --- | --- |
| Per-spectrum event positions (spectra × wavelength heatmap, markers on anomalies, merging contiguous flags into one physical event) | `IntegrityPanel.tsx` (heatmap shown as unavailable; inspection centred on the picked band) | Methods `diagnostics.spectral_population_events_qc` (emit per-row flagged positions, e.g. a sparse `(row, band, type, score)` list and max score) → Preflight engine (`intrinsic.events.*_positions`) → nirs4all-ui selector | The 1.4.1 kernel returns only per-row counts and per-band counts; recomputing it in the demo would duplicate the owner kernel | Add the output in Methods (ABI minor), report it in the engine, then render the heatmap/markers and deduplicate contiguous events from it |
